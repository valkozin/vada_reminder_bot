# 🔔 Приватный Telegram-бот напоминаний на Vercel (без ИИ)

Бесплатный аналог **Skeddy**, работающий 24/7 на **Vercel** с базой **Upstash Redis** и разбором естественного русского языка обычными регулярками — без платных ИИ-сервисов.

---

## 🚀 Возможности

- 🔒 **Приватность:** напоминания лежат только в вашей личной базе Upstash.
- 💰 **Бесплатно:** Vercel Hobby + Upstash Free Tier + внешний cron.
- 🧠 **Парсер русского языка без ИИ.** Время можно писать **в любом месте фразы**:
  - `напомни полить цветок через минуту`
  - `полить цветок через минуту`
  - `через минуту напомни полить цветок`
  - `через полчаса` / `через 1 час 30 минут` / `через пять минут` / `через неделю`
  - `завтра в 15:00 забрать посылку`, `купить хлеб сегодня вечером`, `завтра утром`
  - `в 9 утра`, `в 7 вечера`, `в пятницу в 18:00`
  - Минуты необязательны: `в понедельник в 10`, `завтра в 18`, `каждый день в 9`
  - `25.12 в 12:00`, `15 сентября в 10:00`
  - Повторы: `каждый день в 09:00`, `по будням в 09:00`, `каждую пятницу в 18:00`, `каждое 15 число в 12:00`
  - Слова-связки (`напомни`, `напомни мне что`, `не забыть`) не попадают в текст задачи.
- ⌨️ **Постоянные кнопки** под полем ввода: «📋 Мои напоминания», «🌍 Часовой пояс», «❓ Помощь» — плюс меню команд по кнопке «/».
- 📋 **Список с постраничной навигацией** по 5 напоминаний. Нажатие на номер открывает карточку, где можно **изменить текст**, **изменить время** или удалить. Удалить всё сразу — команда `/clear` с подтверждением.
- ⏰ **Отложить** прямо из уведомления: +15 мин, +1 час, +3 часа, завтра, произвольное время.
- 🌍 **Часовые пояса Европы в один тап**, по умолчанию `Europe/Zurich`. Любую другую зону можно задать вручную: `/tz Asia/Tokyo`.
- 🗂 **Страница со всеми задачами** (Telegram Mini App): весь список сразу, редактирование текста и времени, удаление. Открывается кнопкой «🗂 Все задачи», командой `/app` или кнопкой ☰ рядом с полем ввода.
- 🌐 **Дашборд** с интерактивной песочницей парсера.
- 🎨 **Логотип** — `public/logo.svg` (исходник) и `public/logo.png` 512×512. Он же используется как иконка сайта. Поставить аватаркой бота: @BotFather → `/setuserpic` (Bot API не умеет менять аватар бота, только вручную).

## 📖 Пошаговая установка

### Шаг 1: Бот в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задайте имя и username.
3. Скопируйте **API Token**.

### Шаг 2: База Upstash Redis
1. [upstash.com](https://upstash.com) → **Create Database** → тип **Redis**, регион поближе (например, `eu-central-1`).
2. В разделе **REST API** скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

### Шаг 3: Деплой на Vercel
1. Опубликуйте проект на GitHub.
2. [vercel.com](https://vercel.com) → **Add New… → Project** → выберите репозиторий.
3. В **Environment Variables** добавьте (см. `.env.example`):
   - `TELEGRAM_BOT_TOKEN`
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
   - `CRON_SECRET` — любая придуманная строка
   - `TELEGRAM_ALLOWED_USER_IDS` — ваш Telegram ID (необязательно)
   - `TELEGRAM_WEBHOOK_SECRET` — ещё одна случайная строка (необязательно, но желательно)
4. **Deploy**.

> ⚠️ Переменные, добавленные **после** деплоя, не подхватываются автоматически — сделайте **Redeploy**.

### Шаг 4: Привязка вебхука и меню команд

Откройте в браузере (подставьте свои значения):

```
https://ВАШ-ПРОЕКТ.vercel.app/api/setup?secret=ВАШ_CRON_SECRET&setWebhook=1
```

Один запрос делает всё: привязывает вебхук на правильный адрес, регистрирует меню команд, включает кнопку меню и возвращает диагностику.

Без `&setWebhook=1` тот же адрес работает как **проверка состояния**: показывает, какие переменные окружения заданы, куда сейчас указывает вебхук и какая была последняя ошибка доставки от Telegram.

<details>
<summary>Привязать вебхук вручную</summary>

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://ВАШ-ПРОЕКТ.vercel.app/api/telegram-webhook
```

Адрес должен заканчиваться на `/api/telegram-webhook`. Если указать корень сайта, Telegram получит `405 Method Not Allowed` и бот будет молчать.
</details>

### Шаг 5: Внешний cron (проверка раз в минуту)

Внутренний cron Vercel на тарифе Hobby запускается только раз в сутки, поэтому используется бесплатный внешний сервис.

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) → **Create Cronjob**.
2. URL: `https://ВАШ-ПРОЕКТ.vercel.app/api/cron`
3. **Execution schedule:** `Every 1 minute`.
4. Вкладка **Headers** → добавьте `Authorization` = `Bearer ВАШ_CRON_SECRET`.
5. **Create**.

Проверить вручную: `https://ВАШ-ПРОЕКТ.vercel.app/api/cron?secret=ВАШ_CRON_SECRET` — должен вернуться JSON с `"ok": true`.

## 🗂 Страница со списком задач

Весь список на одном экране, без листания по страницам чата: `/app`, кнопка «🗂 Все задачи» или ☰ рядом с полем ввода.

**Авторизация без паролей.** Telegram передаёт странице подписанный `initData`. Подпись проверяется на сервере ключом, выведённым из токена бота, так что подделать её без токена невозможно. ID пользователя берётся **только** из проверенной подписи, никогда из тела запроса, а право владения перепроверяется в базе на каждой правке и удалении. Запуск живёт 24 часа; список `TELEGRAM_ALLOWED_USER_IDS` действует и здесь.

**Адрес.** На Vercel определяется автоматически. Если у проекта свой домен — задайте `APP_PUBLIC_URL` и откройте `/api/setup?secret=...`, чтобы обновить кнопку меню.

> ℹ️ Мини-приложение — это **только интерфейс**. Сами напоминания по-прежнему шлёт cron: страница работает, только пока открыта, и ничего не делает в фоне.

## 🔐 Шифрование напоминаний

Работает само, настраивать ничего не нужно.

Тексты напоминаний хранятся в Upstash как **AES-256-GCM** шифротекст. Мастер-ключ выводится через **HKDF-SHA256** из `TELEGRAM_BOT_TOKEN` — токен уже лежит в переменных Vercel, и в базе его нет. Поэтому дамп базы без доступа к переменным окружения расшифровать нельзя. Отдельный ключ генерировать и хранить не требуется.

Поверх этого у каждого пользователя **свой** ключ, выведенный из мастер-ключа и его Telegram ID, а каждый шифротекст привязан к паре «пользователь + напоминание» (GCM AAD). Записи одного пользователя **невозможно** прочитать в контексте другого — ни по ошибке в коде, ни подменой ID, ни копированием записей в базе: расшифровка не возвращает чужой текст, а честно падает.

> ℹ️ Ключ намеренно **не** выводится из Telegram ID: ID лежит в той же базе рядом с шифротекстом, а код открыт — такой «ключ» дал бы видимость защиты, а не защиту.

**Что защищено:** утечка или дамп базы Upstash, доступ сотрудников хостинга к данным.
**Что не защищено:** сам Telegram (Bot API не поддерживает end-to-end — доставленное сообщение по определению открытое) и переменные окружения Vercel. Расшифровка на самом телефоне технически невозможна: официальный клиент Telegram не может выполнять чужой код.

### ⚠️ Единственный подводный камень: смена токена бота

Если отозвать или перевыпустить токен в BotFather, выведенный из него ключ исчезнет и **старые тексты станут нечитаемыми** (в списке они покажутся как `🔒 не удалось расшифровать`). Время срабатывания и повторы при этом не теряются.

Если когда-нибудь понадобится сменить токен — **сначала** зафиксируйте текущий ключ:

1. Откройте `https://ВАШ-ПРОЕКТ.vercel.app/api/setup?secret=ВАШ_CRON_SECRET&exportKey=1`
2. Скопируйте `storage.masterKeyBase64` в переменную `ENCRYPTION_KEY` на Vercel, сделайте **Redeploy**.
3. После этого токен можно менять свободно.

Оба ключа проверяются при расшифровке, поэтому переход между ними бесшовный: старые записи продолжают открываться, новые пишутся основным ключом. Записи, созданные до включения шифрования, читаются как открытый текст и шифруются при первом изменении.

## 🛡 Что происходит при сбоях

| Ситуация | Поведение |
|---|---|
| Телефон выключен / авиарежим | Telegram сам держит сообщение в очереди и доставит при подключении. Ничего не теряется. |
| Нет интернета в момент отправки сообщения | Telegram держит его в очереди на телефоне и досылает при подключении. |
| Сообщение дошло с задержкой | Дата считается от времени отправки, а не обработки: «завтра в 9», написанное в 23:58, не уезжает на сутки. |
| Напоминание сохранено, а подтверждение не ушло | Повтор апдейта не создаёт дубликат: блокировка снимается только при сбое базы, когда записи точно не было. |
| Vercel или cron недоступны час | Напоминания остаются в очереди. При восстановлении отправляются все просроченные, начиная с самых старых. |
| Повторяющееся напоминание пропущено несколько раз | Приходит один раз, затем сразу переносится на ближайшее будущее срабатывание — «долгов» не копится. |
| Два запуска cron наложились друг на друга | Атомарная блокировка на конкретное время срабатывания: доставит только один. Дублей не будет. |
| Telegram повторно прислал тот же апдейт | Дедупликация по `update_id` — второе напоминание не создастся. |
| Telegram или база временно ответили ошибкой | Блокировка снимается, следующий запуск (через минуту) повторит доставку. |
| Пользователь заблокировал или удалил бота | Напоминания **не удаляются**, а переводятся в статус «приостановлено». После `/start` восстанавливаются, просроченные приходят сразу. |
| База недоступна в момент создания напоминания | Пользователь получает явное сообщение «не сохранено, отправьте ещё раз» — молчаливой потери нет. |
| Несколько пользователей | Полная изоляция: списки по владельцу, проверка владельца на каждой кнопке, разные ключи шифрования. |
| Сменён токен бота | Тексты старых напоминаний станут нечитаемыми, если заранее не зафиксировать ключ (см. «Шифрование»). Расписание не теряется. |
| Переход на летнее/зимнее время | Повторы считаются по локальному времени пользователя, «каждый день в 09:00» остаётся в 09:00. |
| Очень длинный список | Разбивается на страницы по 20 — лимит Telegram в 4096 символов не достигается. |

## 🩺 Если бот молчит

| Симптом | Причина | Что делать |
|---|---|---|
| Бот не отвечает вообще | Вебхук не привязан или указывает не туда | Открыть `/api/setup?secret=…` и посмотреть `webhookInfo` |
| `405 Method Not Allowed` в `getWebhookInfo` | Вебхук указывает на корень сайта | Перепривязать с суффиксом `/api/telegram-webhook` |
| `401 Unauthorized` | Включена Vercel Deployment Protection | Settings → Deployment Protection → Vercel Authentication → Disabled |
| Напоминания создаются, но не приходят | Не настроен внешний cron (Шаг 5) | Проверить задание на cron-job.org |
| Напоминания пропадают | Не заданы переменные Upstash | `/api/setup` покажет предупреждение о работе «в памяти» |

## 🗂 Структура

```
src/
  lib/
    parser.ts      # разбор русских дат + расчёт следующего повтора
    parser.test.ts # тесты парсера (падают с кодом 1 при ошибке)
    reliability.test.ts # шифрование, изоляция пользователей, сбои доставки
    crypto.ts      # AES-256-GCM, ключ из токена бота + ключ на пользователя (HKDF)
    bot.ts         # команды, кнопки, обработчики grammy
    db.ts          # Upstash Redis + fallback в память
    timezones.ts   # список европейских зон, зона по умолчанию
    types.ts
  app/
    api/telegram-webhook/  # приём апдейтов от Telegram
    api/cron/              # рассылка созревших напоминаний
    api/setup/             # диагностика и привязка вебхука
    page.tsx               # дашборд с песочницей парсера
```
