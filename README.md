# 🔔 Приватный Telegram-бот Напоминаний на Vercel (Без ИИ)

Полноценный, бесплатный аналог бота **Skeddy**, работающий в бессерверном режиме на **Vercel** 24/7 с базой данных **Upstash Redis** и поддержкой естественного русского языка (без сторонних платных ИИ!).

---

## 🚀 Особенности

- 🔒 **100% Приватность:** Ваши напоминания хранятся только в вашей личной базе данных Upstash.
- 💰 **Бесплатно навсегда:** Использует бесплатные тарифы Vercel (Hobby) и Upstash Redis (Free Tier).
- 🧠 **Умный парсер русского языка (без ИИ):**
  - Относительное время: `через 15 минут проверить духовку`, `через 2 часа позвонить`
  - Точное время: `завтра в 15:30 полить цветы`, `сегодня в 19:00 купить хлеб`, `послезавтра в 12:00`
  - Дни недели: `в понедельник в 10:00 совещание`, `в пятницу в 18:00 отчет`
  - Числа и месяцы: `15 сентября в 10:00`, `25.12 в 12:00`
  - Повторяющиеся задачи: `каждый день в 09:00 зарядка`, `по будням в 09:00`, `каждую пятницу в 18:00`
- ⏰ **Удобные кнопки:**
  - Отложить на `+10 минут` или `+1 час` прямо из сообщения с напоминанием.
  - Удалить или посмотреть все активные задачи через `/list`.
- 🌍 **Поддержка часовых поясов:** команда `/tz Europe/Moscow` или любой другой город.
- 🌐 **Встроенный веб-сайт (Dashboard):** Красивая панель управления с интерактивным тестированием парсера дат.

## 📖 Пошаговая инструкция по запуску

### Шаг 1: Создание бота в Telegram
1. Откройте в Telegram бот [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя (например, `Мои Напоминания`) и username (например, `my_cool_reminder_bot`).
4. Скопируйте **API Token** бота (например, `7123456789:AAFg...`).

### Шаг 2: Создание бесплатной базы данных в Upstash
1. Перейдите на сайт [upstash.com](https://upstash.com) и зарегистрируйтесь (можно в 1 клик через GitHub).
2. Нажмите кнопку **Create Database**.
3. Введите название (например, `reminder-db`), выберите тип **Redis**, регион **eu-west-1 (Frankfurt)**.
4. В разделе **REST API** скопируйте две строки:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

### Шаг 3: Деплой на Vercel
1. Создайте репозиторий на [GitHub](https://github.com) и опубликуйте этот проект.
2. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub.
3. Нажмите **Add New...** → **Project** и выберите ваш репозиторий.
4. В разделе **Environment Variables** добавьте следующие переменные:
   - `TELEGRAM_BOT_TOKEN`: токен от BotFather
   - `UPSTASH_REDIS_REST_URL`: URL из Upstash
   - `UPSTASH_REDIS_REST_TOKEN`: Token из Upstash
   - `CRON_SECRET`: любая придуманная вами секретная строка (например: `my_super_secret_cron_pass_123`)
   - `TELEGRAM_ALLOWED_USER_IDS`: ваш Telegram ID (необязательно; если указать, бот будет отвечать только вам, узнать свой ID можно у `@userinfobot`).
5. Нажмите **Deploy**.
6. Через 30–60 секунд Vercel выдаст ссылку на ваш сайт, например: `https://my-reminder-bot.vercel.app`.

### Шаг 4: Привязка Telegram Webhook
Откройте браузер и вставьте ссылку (подставив ваш токен и адрес с Vercel):
```
https://api.telegram.org/bot<ВАШ_TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<ВАШ_ПРОЕКТ_НА_VERCEL>.vercel.app/api/telegram-webhook
```
В браузере должно появиться:
```json
{"ok": true, "result": true, "description": "Webhook was set"}
```

### Шаг 5: Настройка расписания Cron (Отправка каждую минуту)
1. Зарегистрируйтесь на бесплатном сервисе [cron-job.org](https://cron-job.org).
2. Нажмите **Create Cronjob**.
3. Укажите URL:
   ```
   https://<ВАШ_ПРОЕКТ_НА_VERCEL>.vercel.app/api/cron
   ```
4. В поле **Execution schedule** выберите: `Every 1 minute`.
5. Перейдите во вкладку **Headers** и добавьте заголовок:
   - **Header:** `Authorization`
   - **Value:** `Bearer <ВАШ_CRON_SECRET>`
6. Нажмите **Create**.

Теперь каждую минуту сервис будет проверять и моментально отправлять вам все созревшие напоминания! 🎉
